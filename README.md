# TUPM-Student-Schedule-Scraper

TUPM Student Schedule Scraper is a Python desktop application that logs in to the TUPM AIMS portal, fetches your class schedule, and displays it in a clean GUI with filtering and local save support.

Built with: Python, CustomTkinter (UI), Selenium (web automation), BeautifulSoup4 (HTML parsing), and Pillow (image handling).

How to run locally:

1. pip install -r requirements.txt
2. python gui.py (depending on your entry file setup)
